## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
    >Red bar แรกพิสูจน์ว่าชุดทดสอบ (Test) ของเราทำงานจริง และมีความสามารถในการตรวจจับข้อผิดพลาดเมื่อซอฟต์แวร์ยังไม่มีคุณสมบัตินั้น หากเห็นเฉพาะ Green bar ตั้งแต่แรก อาจเกิดจากการเขียน Test ที่ผ่านตลอดเวลาโดยไม่ได้ตรวจสอบ Logic จริง (False positive) หรือไม่ได้ทำการทดสอบเงื่อนไขนั้นอย่างแท้จริง การเห็น Red ก่อน Green จึงช่วยเพิ่มความมั่นใจว่า โค้ดที่เราเขียนเพิ่มคือสิ่งที่ทำให้การทดสอบผ่านจริง ๆ
2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
    >สามารถกู้งานทั้งหมดกลับมาได้โดยการ Clone ซอร์สโค้ดจาก Remote Repository บน GitHub ลงมายังเครื่องใหม่ เงื่อนไขสำคัญคือต้องบันทึกประวัติการทำงานด้วย Git (git commit) และส่งโค้ดขึ้นระบบคลาวด์ (git push) อย่างสม่ำเสมอก่อนที่เครื่องจะหาย หากเตรียมทุกอย่างไว้เรียบร้อย เพียงแค่ติดตั้ง JDK, Git และ IDE บนเครื่องใหม่ ก็จะสามารถดึงงานกลับมาพัฒนาต่อได้ทันที
